A tiny Node 22 (stdlib-only) program that writes one line — a one-star review of Monday, written as though Monday were a restaurant — to `/output/entry.txt` and prints it to stdout.

## Run

```sh
node main.ts
```

## The line

> One star. Seated at 6am, the special was dread, the Wi-Fi was down, and the waiter — Monday himself — never smiled.
